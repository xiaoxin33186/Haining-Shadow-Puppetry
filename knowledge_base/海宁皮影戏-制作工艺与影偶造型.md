# 海宁皮影戏——制作工艺与影偶造型

## 一、核心造型特点

海宁皮影戏的影偶造型在全国皮影流派中独树一帜，其核心特点概括为九个字：

> **"少雕镂、重彩绘、单线平涂"**

这三点是海宁皮影区别于河北、陕西等其他地区皮影（重雕镂、造型夸张）的显著标志。

### 造型风格详述

| 特点 | 说明 |
|------|------|
| 脸形圆活 | 脸部轮廓圆润柔和，不似北方皮影的棱角分明 |
| 单眼侧面 | 影偶以侧面呈现，单眼勾勒，这是南宋传统造型的遗风 |
| 少夸张 | 不追求过度变形，接近真实人像比例 |
| 近实像 | 造型写实，贴近人物本来面貌 |
| 富"人情"味 | 表情神态自然亲切，不冰冷刻板 |
| 单手并足（侧身） | 整体以单手、侧身并足为主，传统造型特色鲜明 |

> **来源**: 百科、搜狐、头条（漂洋过海 海宁皮影戏即将亮相台湾）

## 二、制作材料

海宁皮影的传统材料有两种：

- **牛皮**: 最为常用，韧性好，透光性佳
- **羊皮**: 质地更细腻柔软，适用于精细部件

选材要求严格：须选用优质无瑕疵的皮张，经反复清洗去其油垢。

> **来源**: 百科、搜狐（解锁国家级非遗三大"硬核"技艺）

## 三、完整制作工序

海宁皮影的制作前后共有**数十道工序**，主要分为以下步骤：

### 第一步：选材与处理
牛皮/羊皮 → 去毛 → 刮挺 → 去脂 → 拉紧晒干 → 压平

### 第二步：画稿设计
按照人物的不同身份（生、旦、净、丑）和个性，设计出不同的形象画稿。这一步决定了影偶的整体气质和角色特征。

### 第三步：拷贝上皮
将设计好的画稿拷贝转移到经加工过的皮面上。

### 第四步：勾线（关键工序）
以毛笔在皮面上勾出轮廓线条。**勾线是海宁皮影最具艺术功力的一道工序**，一笔一描马虎不得。如绘勾须鬓纤眉，须根根见底、纹丝不乱，造型精到，方能显示南宋传统遗风。

### 第五步：上色
根据人物角色身份涂上不同色彩。海宁皮影的彩绘极重，一个人物就是一幅**工笔重彩的国画**。不同角色施以不同色彩，遵循传统配色规范。

### 第六步：罩漆
待颜料干透后，用白桐油或清漆涂刷一遍。作用有二：
- 增加光泽度和透明度
- 防霉变，延长影偶寿命

### 第七步：缝接
取针线将影偶身体各部位用不同针法缝制联接。由于皮影人物是肢解完成的，各部件（头、身、四肢）需分别制作后再缝合成整体。同一个角色在剧情中可能需换几次头面（头部），以适应不同情绪和身份变化。

### 第八步：上签
在影偶背后装上翎管，套进竹签棒。签棒数量因角色而异：
- **最少**: 两根（简单动作）
- **复杂形体**: 多达六七根

现代剧目中的影偶改为双手双脚造型，增加竹签数量，由多人分别操持，动感更强。

> **来源**: 百科、搜狐（海宁皮影戏《大闹天宫》）

## 四、影偶角色分类

海宁皮影戏影偶按传统戏曲角色分为：

| 角色类型 | 京剧对应 | 造型特征 |
|----------|---------|----------|
| 生 | 小生、老生 | 眉清目秀，文雅端庄 |
| 旦 | 青衣、花旦 | 面容秀丽，服饰华美 |
| 净 | 花脸 | 面部浓彩，威武刚猛 |
| 丑 | 丑角 | 滑稽夸张，引人发笑 |

脸谱既接近于京剧又不同于京剧，按忠、奸、贤、义的不同性格，以喜怒哀乐的不同表情加以夸张塑造。

> **来源**: 百科

## 五、与其他地区皮影制作的对比

| 对比维度 | 海宁皮影 | 河北唐山皮影 | 陕西华县皮影 |
|----------|----------|-------------|-------------|
| 核心特点 | 少雕镂、重彩绘、单线平涂 | 雕镂精细、刀法多变 | 精雕细刻、古朴厚重 |
| 用材 | 牛皮/羊皮 | 驴皮为主 | 牛皮为主 |
| 造型风格 | 圆活近实、富人情味 | 造型夸张、脸谱化 | 侧面、通天鼻梁 |
| 上色方式 | 工笔重彩、单线平涂 | 分染套色 | 传统五色 |

> **来源**: 百科综合整理

## 六、现代制作与创新

- 现有新制皮影多为斜桥剪纸艺人、浙江省民间艺术家**王钱松**（被誉为"江南剪纸王"）所制。
- 由于南宋传统造型中人物角色在具体戏本中通用，没有固定人物名，现代制作的影偶人物上挂了牌，注明了通用角色名，便于管理和使用。

> **来源**: 百科

## 七、纹样美学与装饰符号

海宁皮影戏的纹样不仅装饰影偶，更承载着丰富的文化寓意和符号价值。影偶服饰上的纹样布局严谨，每一笔描画都有其文化含义。

### 主要纹样类型及寓意

| 纹样类型 | 造型特征 | 文化寓意 | 常用部位 |
|----------|----------|----------|----------|
| 龙纹 | 盘旋蜿蜒，五爪或四爪 | 至尊权威，身份象征 | 帝王将相的袍服 |
| 云纹 | 卷曲流动，轻盈飘逸 | 祥瑞吉庆，灵动高远 | 服饰边缘、背景装饰 |
| 水纹 | 波浪层叠 | 江海浩瀚，水乡特色 | 下摆、袖口 |
| 花卉纹 | 牡丹、莲花、梅花等 | 富贵、高洁、坚韧 | 女性角色的裙衫 |
| 几何纹 | 回纹、方胜、如意纹 | 福寿绵长，吉祥如意 | 衣领、腰带、边框 |

### 色彩体系

海宁皮影的色彩遵循中国传统配色规范：

| 色彩 | 角色身份 | 象征意义 |
|------|----------|----------|
| 红色 | 忠勇之士、帝王 | 正义、权威 |
| 黑色 | 刚正不阿、武将 | 刚毅、勇猛 |
| 白色 | 奸诈之徒、书生 | 奸滑或文雅 |
| 绿色/蓝色 | 草莽英雄、妖怪 | 野性、神秘 |
| 金色/黄色 | 神仙、帝王 | 神圣、至尊 |

> **来源**: 百科、杭州电子科技大学学报（基于符号学的海宁皮影图案解析与设计研究）、豆丁网（海宁皮影纹样在装饰画中的运用探析）

## 八、皮影舞台美术

### 银幕（纸幕）
海宁皮影戏传统使用**三尺白色生绢**作为戏台，古人诗云"**三尺生绢做戏台，全凭十指逞诙谐**"。现代也有使用白色纸幕的做法。幕布是光影魔术的核心——强光从幕后照射，使影偶在观众面前呈现通体透明、色彩鲜艳的视觉效果。

### 光影原理
- 影偶与幕布紧贴，颜色和轮廓最清晰
- 影偶远离幕布则形象模糊、色彩暗淡
- 艺人通过控制影偶与幕布的距离产生远近深浅变化
- 有时明月灯窗下，一笑还从掌握来——灯光的运用是皮影的灵魂

> **来源**: 百科、头条（漂洋过海海宁皮影戏亮相台湾）
