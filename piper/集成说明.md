# piper 文件夹集成说明

> 本文件夹是 **Piper TTS 的程序本体**（离线文字转语音引擎），配合 `piper2` 文件夹里的 `tts_engine.py` 使用。

## 一、文件夹结构

```
Desktop\piper\
├── piper\                              ← Piper 主程序目录
│   ├── piper.exe                       ← 主程序（命令行 TTS 引擎）
│   ├── espeak-ng.dll                   ← 语音合成底层库
│   ├── espeak-ng-data\                 ← 语言数据（含中文 cmn）
│   ├── onnxruntime.dll                 ← 神经网络推理引擎
│   ├── onnxruntime_providers_shared.dll← 推理引擎共享库
│   ├── piper_phonemize.dll             ← 文本转音素库
│   └── libtashkeel_model.ort           ← 阿拉伯语模型（中文用不到，可删）
├── zh_CN-huayan-medium.onnx            ← 中文语音模型（约 60MB，核心）
└── zh_CN-huayan-medium.onnx.json       ← 中文语音模型配置（音色/采样率）
```

| 文件/目录 | 作用 | 是否必需 |
|-----------|------|---------|
| `piper\piper.exe` | 主程序 | ✅ 必需 |
| `piper\espeak-ng.dll` + `espeak-ng-data\` | 文本→音素转换 | ✅ 必需 |
| `piper\onnxruntime.dll` | 模型推理 | ✅ 必需 |
| `piper\onnxruntime_providers_shared.dll` | 推理共享库 | ✅ 必需 |
| `piper\piper_phonemize.dll` | 音素处理 | ✅ 必需 |
| `zh_CN-huayan-medium.onnx` | 中文语音模型 | ✅ 必需 |
| `zh_CN-huayan-medium.onnx.json` | 语音模型配置 | ✅ 必需 |
| `piper\libtashkeel_model.ort` | 阿拉伯语模型 | ❌ 中文用不到 |

## 二、如何与 tts_engine.py 对接

在 `piper2\tts_engine.py` 顶部，把三个路径改成指向本文件夹：

```python
PIPER_EXE = r"C:\Users\Administrator\Desktop\piper\piper\piper.exe"
VOICE_MODEL = r"C:\Users\Administrator\Desktop\piper\zh_CN-huayan-medium.onnx"
PIPER_DIR = r"C:\Users\Administrator\Desktop\piper\piper"
```

## 三、手动测试（不用跑整个项目）

用 CMD 直接合成一段语音：

```
echo 海宁皮影戏测试 > test.txt
"C:\Users\Administrator\Desktop\piper\piper\piper.exe" -m "C:\Users\Administrator\Desktop\piper\zh_CN-huayan-medium.onnx" -f test.wav < test.txt
```

成功后会生成 `test.wav`，双击就能播放。

## 四、关键注意

1. **路径不能有中文** —— `espeak-ng` 读中文路径会报 `Illegal byte sequence`，所以本文件夹放在 `Desktop`（英文路径）下没问题，但**不能放到 `D:\海宁皮影戏` 这种中文路径里**。
2. **文本必须走 stdin**（`< test.txt` 或管道），`-f` 参数是**输出** wav 文件，不是输入。
3. 若要换音色，可去 `hf-mirror.com/rhasspy/piper-voices` 下载其他中文语音（如 `zh_CN-huayan-x_low`、`zh_CN-libritts_r-medium`），替换 `zh_CN-huayan-medium.onnx` 和对应 `.json` 即可。
